# Study Memory 1.0

Личное PWA-приложение для Android: карточки, тесты, изображения, интервальное повторение, светлая/тёмная тема и резервное копирование.

## Состав
- `index.html` — интерфейс
- `styles.css` — адаптивный минималистичный дизайн
- `app.js` — логика, IndexedDB, карточки, тесты, интервалы, импорт/экспорт
- `manifest.webmanifest` — параметры установки PWA
- `service-worker.js` — кэширование для офлайн-работы
- `icon.svg` — значок

## Как запустить на Android
PWA устанавливается с HTTPS-сайта или локального сервера. Просто открыть `index.html` из файлового менеджера недостаточно для установки и Service Worker.

Самый простой способ:
1. Распаковать архив на компьютере.
2. Разместить содержимое папки на статическом HTTPS-хостинге (например, GitHub Pages или Netlify).
3. Открыть полученную HTTPS-ссылку в Chrome на Android.
4. В меню Chrome выбрать «Установить приложение» или «Добавить на главный экран».
5. Открыть приложение и создать резервную копию после добавления своих материалов.

После первой загрузки приложение кэширует свои файлы и может открываться офлайн. Данные карточек и изображения хранятся локально в IndexedDB браузера на устройстве.

## Важно о данных
- Не очищайте данные сайта/браузера без резервной копии.
- Экспорт создаёт JSON-файл с наборами, карточками, расписанием и изображениями.
- Импорт объединяет записи по ID; существующие записи с тем же ID обновляются.
- Резервную копию храните отдельно от телефона.

## Алгоритм повторения
В этой версии используется простая система коробок Лейтнера с интервалами 1, 2, 4, 8, 16 и 30 дней. Это стартовая реализация, не точная копия алгоритмов Anki/FSRS.

## Ограничения первой версии
- Нет облачной синхронизации и аккаунта.
- Тесты с выбором ответа формируют варианты из ответов других карточек того же набора; если карточек мало, вариантов будет меньше.
- Пока нет интерактивной разметки областей на изображениях.
- Приложение предназначено для личного использования, не является медицинским или экзаменационным оценщиком.
