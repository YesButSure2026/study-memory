# Study Memory 2.0 — интерактивные изображения (beta)

Study Memory — локальное PWA-приложение для учебных карточек и повторения. Интерфейс на русском языке, поддерживает установку на Android и офлайн-работу.

## Что нового в 2.0 beta

- Интерактивные изображения создаются отдельно от обычных карточек. Старые карточки и прикреплённые к ним изображения не преобразуются и продолжают работать как раньше.
- Для интерактивного изображения можно добавить точечные метки и свободные контуры.
- Для каждой структуры задаются название, варианты названия и пояснение.
- В редакторе доступны выбор/перемещение метки, перемещение изображения, масштабирование, отмена последнего действия, цвет и прозрачность подсветки.
- Можно выбрать несколько изображений из одной учебной колоды для занятия.
- Два режима занятия: «Определи выделенную структуру» и «Найди структуру на изображении».
- Для режима определения доступны самооценка или ввод названия с локальной проверкой по названию и синонимам.
- Структуры предъявляются в случайном порядке. После проверки показывается правильная структура и пояснение.
- Прогресс сохраняется в IndexedDB после каждого ответа; статистика ведётся по отдельным структурам.
- Резервная копия включает обычные карточки, изображения, интерактивные материалы и их статистику. Старые JSON-копии версии 1 также импортируются.

## Установка / обновление

1. Сделайте экспорт JSON-резервной копии в установленном приложении.
2. Замените файлы проекта в корне GitHub-репозитория файлами из этой папки.
3. Дождитесь обновления GitHub Pages.
4. Откройте приложение онлайн, чтобы загрузить новую версию. Если старая версия осталась в кеше, закройте приложение и откройте сайт в браузере; затем перезапустите установленное PWA.

## Хранение данных и миграция

- Используется IndexedDB `study-memory-db`.
- Версия схемы повышена с 1 до 2. При открытии существующей базы создаётся новое хранилище `interactive`; существующие хранилища `decks`, `cards` и `meta` не удаляются и не пересоздаются.
- Интерактивные материалы сохраняются отдельно в object store `interactive`.
- Данные хранятся локально на устройстве. Очистка данных сайта/браузера может удалить их — регулярно экспортируйте резервную копию.

## Технические замечания

- Приложение не использует сервер для распознавания ответов: проверка текста выполняется локально по точному совпадению после нормализации регистра, пробелов и `ё/е`, с учётом заданных синонимов.
- Пространственная проверка использует попадание внутрь контура или допустимую близость к нему; для точек предусмотрена зона допуска вокруг метки.
- Это beta-реализация. Перед использованием как единственной копии материалов проверьте создание, редактирование, экспорт и импорт на своём устройстве.

## Состав

- `index.html` — интерфейс приложения
- `styles.css` — оформление
- `app.js` — логика приложения и IndexedDB
- `service-worker.js` — кеширование и офлайн-работа
- `manifest.webmanifest` — параметры PWA
- `icon.svg` — значок приложения
